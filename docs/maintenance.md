# 维护与视觉验收

## 设计约定

黑白灰底色、磨砂玻璃、柔和光影与清晰的中文标题。界面不使用彩色强调；个人照片保留原有色彩，不应用黑白滤镜。材料与容器宽度统一放在 `src/styles/tokens.css`；布局和断点集中在 `src/index.css`。

正文始终直接可见，不依赖滚动动画触发。项目图形是本地 SVG 技术概念图；项目指标来自原始项目资料，不代表不同平台之间的统一基准测试。

## 更新照片

历史照片归档在 `assets/originals/`。新增原图保留于本地 `images/`（已加入 Git 忽略），在压缩脚本中登记后运行 `npm run images` 生成无元数据的网页副本，再更新 profile.ts 的路径和固有尺寸。应先查看原图与生成结果，确认展示位置没有裁掉主体。不要将简历、实习报告、证件、成绩单等原始材料复制进仓库。

## 发布验收

- 执行 `npm run lint`、`npm run check:public`、`npm run build`。
- 在生产预览查看 1440px 桌面、768px 平板、390px 手机以及 320px 窄屏。
- 亲自检查首屏、所有章节、底部、项目展开状态与移动导航截图。
- 检查页面无横向滚动，图片全部加载，控制台无错误。
- 影像区使用懒加载，全页截图前先滚动经过所有照片并等待解码；不要将未触发懒加载的空白截图误认为完整验收。
- 点击导航，验证锚点不被页头遮挡；移动菜单应支持关闭、选择导航和 Escape。
- 验证每个项目详情展开/收起，邮箱复制反馈及外部链接。
- 使用减少动态效果设置验证内容可见。
- 发布成功后再次打开线上页面，核对最新资源哈希并复查桌面和手机。

本地截图存放于 `output/playwright/`，该目录不提交到 Git。
