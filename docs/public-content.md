## 不公开的信息

不提交原始申请材料、实习报告、证件、成绩单、证书扫描件、签名印章、学号、身份证号、私人电话、住址、导师联系方式、内部项目名、客户信息、系统地址、访问凭据或业务资料。页面仅保留既有公开邮箱与 GitHub 联系入口。

新增原始照片保留在 Git 忽略的 `images/`，只提交压缩后的 WebP；图片副本去除 EXIF、XMP 与 IPTC。照片保留原有色彩，不使用黑白滤镜，不改动原图。

## 发布检查

`npm run check:public` 扫描网页来源中的常见证件号、电话和密钥模式，并检查公开图片元数据。该检查只是辅助，无法判断所有商业保密内容；发布前仍须人工核对新增文案和 Git 差异。

本次移除的手机号不再出现在当前网页与构建产物中。既有公开 Git 历史不会因页面更新自动消失；不要在未协调的情况下重写仓库历史。
